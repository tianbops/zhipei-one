# 智配 One

智配 One 是面向个人配送员和小团队的轻量物流工具。产品核心是运单处理、历史查询、路线经验沉淀与轻量协作，而不是 ERP、WMS、TMS 或复杂的智能调度平台。

## 产品目标

- **录入更省事**：手机拍照/上传、OCR 识别、人工校正、保存草稿与运单记录。
- **历史可查可复用**：按日期、运单号、线路、姓名、电话、地址等维度查询历史，并在明确匹配时辅助回填。
- **经验能沉淀**：将门店身份、别名、地址、客户信息与线路关系保存为可审核、可维护的规则映射。
- **小团队够用**：保留必要的账号、线路归属和权限，不引入超出实际业务需要的复杂流程。
- **手机优先、数据可靠**：减少操作步骤，兼顾弱网、离线草稿、恢复后同步和数据备份。

## 核心工作流

拍照/上传 → OCR 识别 → 人工核对 → 匹配门店与线路经验 → 保存 → 历史查询与复用。

识别、匹配和保存是不同环节。系统必须展示真实结果与失败原因，不能将未确认的匹配当成事实，也不能虚报 OCR 准确率或部署/备份状态。

## 产品边界

暂不建设 AI 自动调度、自动分单、模型训练或大型 ERP/TMS 功能。优先使用可解释的规则、历史记录和人工确认，复杂状态只在确有业务必要时引入。

## 迭代优先级

### V1：录入与历史
1. OCR 识别与手机端校正体验。
2. 历史运单可靠保存、检索、详情和更正。
3. 客户/门店信息的安全回填，避免错误身份合并。
4. 草稿保护、错误提示与关键链路回归测试。

### V2：经验库
1. 路线、门店和客户映射的查询、确认、纠错。
2. 历史复用与基础统计。
3. 冲突提示、变更记录和可追溯性。

### V3：轻量团队协作
1. 必要的成员、线路归属和权限管理。
2. 在明确授权范围内共享经验。
3. 操作日志与数据恢复流程。

### V4：PWA 与离线
1. 离线草稿和网络恢复后的安全同步。
2. 多端一致性与冲突处理。
3. 可验证的备份、导出与恢复演练。

以上是产品优先级，不代表所有能力已经实现。每项功能必须经过真实数据场景、权限边界和失败路径验证后，才能标记完成。

## 免费 OCR 与隐私边界

- 运单图片在浏览器端通过开源 Tesseract.js 进行本地文字识别；正常识别流程只把识别文本提交给运单处理接口，不把原始图片作为 OCR 文件上传。
- 首次使用或浏览器缓存清除后，浏览器需要联网加载识别脚本与中文/英文语言包。语言包加载失败时应显示可理解的错误提示，不得悄悄回退到付费服务。
- 本地 OCR 不代表离线首次可用，也不保证固定识别准确率。需要用真实手机、真实运单截图验证识别效果，并由用户核对关键字段。
- 服务端 OCR 适配层明确拒绝图片识别调用，防止旧流程意外触发外部或付费 OCR 服务。

## 技术与数据原则

- 延续现有仓库与业务架构，先审计、修复和验证，再决定是否重构。
- 业务数据与静态资源分开处理；缓存不能把旧业务数据伪装成最新结果。
- 变更必须保护现有数据，禁止无范围清理或未经验证的迁移。
- 对历史检索设置资源预算和明确的范围限制；预算不足时返回可理解的错误，不静默漏数据。
- 备份、部署和端到端测试只在取得实际执行结果后报告。
