## 版本号约定

- Git 归档 tag 采用语义化版本 `vMAJOR.MINOR.PATCH`。
- 每个归档版本同时记录对应的 Service Worker 运行时版本号（`zp-pwa-N`），
  二者一一对应、可互相追溯：v1.0.0 ↔ `zp-pwa-57`，v1.0.7 ↔ `zp-pwa-58`。
- 后续发布新归档时，按变更性质递增 MAJOR（不兼容变更）/ MINOR（新功能）/ PATCH（修复与优化）。

## 功能范围

PWA 配送应用（MPA + Service Worker 离线优先）：

- **登录/注册**：账号密码登录、注册、登录态持久化
- **首页**：今日配送概览、门店列表（6 家可视，超出框内滚动）、月度统计
- **今日配送详情**：按门店的配送任务明细
- **运单详情**：路线、门店、重量汇总
- **历史**：历史运单列表、滑删删除
- **数据**：配送数据统计
- **我的**：账号信息、修改用户名/密码、注销账号（已并入「账号与安全」）、退出登录；
  「关于」区块含检查更新 + 下载应用（单行：安卓安装包 · 复制网址）
- **管理后台**：admin / admin-bootstrap / setup 引导链路
- **主题**：Uber 风格深/浅双主题，全组件 token 化（WCAG AA 对比度达标）
- **安全**：9 个受保护页渲染前同步登录守卫 + bfcache 兜底 + 登录深链 + 401 回登录
- **安装下载**：安装包站点同域托管（`/downloads/`），稳定文件名 + manifest 版本清单
- **离线**：SW 预缓存 App 壳，离线回退 `/offline`

## 已知事项与后续建议

- `tests/` 与 `tools/` 为开发期产物，仍随站点公开：4 个运维工具页已加登录守卫；
  1 个无害静态测试夹具（observer_probe.html，空列表无数据）按策略保留不设守卫。
  **建议下版将 dev 产物从生产构建中剔除**（Pages 层屏蔽或独立仓库）。
- 手机端工程仓库 `tianbops/zhipei` 仍为私有；用户下载走站点同域，不受可见性影响。
  如需 GitHub 作为备用出口，需所有者网页端将仓库转公开。
- 安装包目前托管在 Cloudflare Pages 同域；用户量上来后可迁国内对象存储
  （腾讯云 COS / 阿里云 OSS）+ CDN 获得更稳速度。
- 前端守卫为体验层拦截，后端接口本就返回 401；如需更强纵深防御，
  可在 API 网关/服务端再加一层鉴权中间件。
