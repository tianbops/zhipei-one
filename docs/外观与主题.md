# 外观与主题（浅色 / 深色 / 字号）

## 实现概览

- 入口在「我的 → 外观与显示」：外观三选一（跟随系统 / 深色 / 浅色）+ 全局文字大小滑杆（0.85–1.3）。
- 偏好只保存在当前浏览器 `localStorage`，不写入业务账号或服务端：
  - `zp_appearance_theme`：`system` | `dark` | `light`
  - `zp_appearance_font_scale`：0.85–1.3 的数字
- 实现在 `js/ui-unified.js` 顶部的 `initAppearancePreferences` IIFE，对外暴露：
  - `zpSetAppearanceTheme(theme)` / `zpGetAppearanceTheme()`
  - `zpSetFontScale(value)` / `zpGetFontScale()`
- 切换会派发 DOM 事件：`zp:appearancechange`、`zp:fontscalechange`（设置页监听它们刷新选中态）。

## 主题生效机制

- `applyTheme` 把解析结果写到 `<html data-zp-theme="light|dark">`，并同步 `meta[name=theme-color]`。
- CSS 侧约定：**深色是默认样式**；浅色全部通过 `:root[data-zp-theme="light"] ...` 覆盖块实现，集中在各 CSS 文件末尾的「浅色外观适配」段落。
- 设计 token 定义在 `css/ui-unified.css`（浅色值见 `:root[data-zp-theme="light"]` 块）：

| Token | 浅色值 | 用途 |
|---|---|---|
| `--zp-bg` | `#F4F6F8` | 页面背景 |
| `--zp-surface` | `#FFFFFF` | 卡片 / 弹层 |
| `--zp-surface-2` | `#F0F2F4` | 次级按钮 / 输入底 |
| `--zp-line` | `#D7DDE3` | 边框 |
| `--zp-text` | `#17202A` | 主文字 |
| `--zp-muted` | `#46515D` | 次级文字 |
| `--zp-soft` | `#66717D` | 弱化文字 |
| `--zp-divider` | `rgba(20,30,40,.12)` | 分隔线 |

- 主按钮浅色统一 `#263746` 白字；错误/危险提示文字统一使用 `#C2453A`；破坏性操作按钮使用浅红底 `#FCEBEC`、深红字 `#8A2630`，按压态使用 `#F5DCDD` / `#741E27`。趋势图涨 `#2E7D4F` / 跌 `#B4472F`。
- 深色主题的 `--zp-danger:#FFB4AB` 是暗底上的浅红提示色；浅色主题必须覆盖为 `--zp-danger:#C2453A`，不可让浅红色落在白色或浅灰背景上。`--ui-danger` 保留给删除/危险动作组件的既有语义，避免把不同用途强行合并造成视觉变化。

## 覆盖范围与维护规范

浅色适配覆盖：登录/注册页（app.css）、首页全套含月度统计卡与上传弹层（home.css）、运单详情（order_detail.css）、线路页（`pages/dispatch.html` 内联 style）、线路申请与账号页（business-pages.css）、数据中心（data.css）、历史页（history.css）、弹窗/Toast/确认框等通用组件（ui-unified.css）。

**新增或修改组件时必须同时给出浅色覆盖**，否则该组件在浅色模式下会以深色样式漏出（历史上线路页整页、运单详情汇总卡、数据页顶部按钮都漏过）。自查方法：本地起静态服务，`localStorage.setItem('zp_appearance_theme','light')` 后逐页目检；可参考 `tools/_shot_theme.py` 的截图脚本思路（脚本为临时工具，不入库）。

## 字号缩放

- `applyScale` 把倍率写入 `<html style="--zp-font-scale">`，并对命中选择器的文本元素按「基准字号 × 倍率」写 inline `font-size !important`，范围钳制 0.85–1.3。
- 基准字号缓存在元素 `dataset.zpFontBase`，首次计算后复用；`MutationObserver` 对后续新增节点补应用。
- 已知边界：inline `!important` 会覆盖页面自身的动态字号调整；新增强字号语义的组件时需要评估。
