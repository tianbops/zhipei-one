## 版本号约定

- Git 归档 tag 采用语义化版本 `vMAJOR.MINOR.PATCH`，**v1.0.0 为第一个正式归档**。
- 每个归档版本同时记录对应的 Service Worker 运行时版本号（`zp-pwa-N`），二者一一对应、可互相追溯。
- 后续发布新归档时，按变更性质递增 MAJOR（不兼容变更）/ MINOR（新功能）/ PATCH（修复与优化）。

## 功能范围

PWA 配送应用（MPA + Service Worker 离线优先）：

- **登录/注册**：账号密码登录、注册、登录态持久化
- **首页**：今日配送概览、门店列表（6 家可视，超出框内滚动）、月度统计
- **今日配送详情**：按门店的配送任务明细
- **运单详情**：路线、门店、重量汇总
- **历史**：历史运单列表、滑删删除
- **数据**：配送数据统计
- **我的**：账号信息、密码与安全、危险操作（注销账号）、退出登录
- **管理后台**：admin / admin-bootstrap / setup 引导链路
- **主题**：深/浅双主题，全组件 token 化
- **离线**：SW 预缓存 App 壳，离线回退 `/offline`
