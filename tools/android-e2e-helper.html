智配One · Android 真机 E2E 自检 Helper

用途：在真机生产 app 页面临时注入一个浮动自检面板，实时显示返回层级 hook 状态并触发 顶部返回 / 物理返回键（history.back），走查《Android 真机 E2E 用例清单》3.1–3.6 时无需肉眼猜状态，结果可一键导出回传。

安全：本脚本仅通过 DevTools Console 临时注入，不留痕、不进仓库、不影响生产。验证完刷新页面即消失。请勿将本载体页本身部署到生产。

一、真机执行步骤

  1. 手机 Chrome 打开生产域名 → 菜单「添加到主屏幕」安装 PWA → 从桌面图标启动（standalone 模式，无地址栏）。
  2. 手机开启 USB 调试，连电脑；桌面 Chrome 打开 chrome://inspect/#devices → 找到智配One 的 WebView/PWA → 点 inspect。
  3. 在打开的 DevTools Console 里粘贴下方「注入脚本」并回车（或点本页 复制注入脚本 后粘贴）。页面出现绿色浮动面板即成功。
  4. 按清单逐步操作：每一步在面板上点 zpHandleBack(顶部) 或 history.back(物理键)，观察 URL 与层级变化，与预期核对。
  5. 手势返回（清单 A1g/A2g/B2g）：从屏幕左边缘右滑，观察 URL 是否变化到预期（应等价于 history.back）。此项面板无法模拟，须手动触发。
  6. SW 升级（清单 S1/S2）：点面板 查SW版本，确认显示 zp-pwa-16。
  7. 走查完点 导出报告 复制 JSON，回传给我判断是否进 P1。
